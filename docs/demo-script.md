# 90秒デモスクリプト

審査員の前で動かす本番ピッチ用。**全体で90秒以内** に収める。

## 配役

- **司会 / フリーランサー役**: Yuki（メイン操作）
- **クライアント役**: 同チームメンバー or 観客指名（盛り上がる）
- **画面**: LINE × 2画面（フリーランサー / クライアント）+ Polygon Amoy Explorer

## バックアッププラン（フェイルセーフ）

| 想定リスク | 対策 |
|-----------|------|
| 会場Wi-Fi切断 | localhost で OpenClaw + Hardhat node を立てて、Amoyでなくlocal chainでデモ可能にしておく |
| LINE webhook 遅延 | ngrok 別ポートで予備の bot account を準備 |
| Amoy RPC 不調 | Alchemy / Ankr の代替RPC を `.env` に予備として用意 |
| LLM応答の揺れ | デモ用プロンプトを system prompt に固定し、温度0.2 |
| 全部ダメな時 | 事前収録した90秒動画を再生 → 質疑応答ベースに切り替え |

## 質疑応答想定

| 想定質問 | 回答方針 |
|---------|---------|
| なぜ JPYC？ | 規制下の正規円ステーブル・FXリスクなし・日本の信頼感 |
| なぜ Polygon？ | JPYC実績・gas安・tooling厚い。本番では実JPYCの選好チェーンに合わせる |
| なぜ LINE？ | 日本90M MAUに直接届く唯一の経路。Telegramでは届かない層 |
| 本番で実JPYC使える？ | 改正資金決済法下でJPYC社が電子決済手段として発行。mainnet切替で対応 |
| AIが誤って release したら？ | agent権限はpayer設定。承認ゲートを必ず挟む。最終的に payer override可 |
| 1社あたり想定収益は？ | 振込手数料代替（@1件¥330）×月100件 = ¥33,000/月、かつ仕分け工数削減 |
