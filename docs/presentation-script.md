## 練習メモ

### スピード調整

- **早すぎる兆候**: スライド1で20秒以下、スライド2で20秒以下 → 1拍置く
- **遅すぎる兆候**: スライド4で35秒超 → 一文飛ばす（"ここが大事…"の段落を削る）

### 強調すべき言葉（ゆっくり・大きく）

- 「**1,200万人**」
- 「**決済まで**自動化できているサービスは、ひとつもありません」
- 「**Bridging AI Reasoning with Blockchain Execution**」
- 「**LINE と JPYC で日本に降ろす**」

### 避けるべき口癖

- 「えーと」「あの」「まあ」 — 言いそうになったら無音にする
- 「〜なんですけど」「〜だったり」 — 言い切る形に

### 緊張対策

- 直前に深呼吸3回
- スライド1を表示してから3秒沈黙してから始める（聞き手を引き込む）
- デモ前に水を一口
